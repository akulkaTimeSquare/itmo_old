# Алгебра Матриц

## Цель работы
Реализовать основные функции для работы с матрицами.

## Задание 
Вычислить значение выражения:
$$X = A \times (\alpha \cdot B + C^T),$$
где $A, B, C$ $-$ произвольные прямоугольные матрицы над полем $\mathbb{R}$ и $\lambda \in \mathbb{R}$ $-$ вещественное число.

## Порядок выполнения работы 
* Реализовать на языке Python в виде функций следующие операции: 
  * Сложение двух матриц;
  * Умножение матрицы на число;
  * Умножение двух матриц;
  * Транспонирование матрицы;
* Реализовать функцию, которая вычисляет матричное выражение:
  $$X = A \times (\lambda \cdot B + C^T)$$

---

## Формат входных данных (файл `input.txt`)
Файл `input.txt` содержит ровно семь строк в указанном порядке: 
* $n_A \phantom{a} m_A$ $-$ два целых числа, количество строк и количество столбцов в матрице $A$; 
* $a_1^1 \phantom{a} a_1^2 \phantom{a} \ldots \phantom{a} a_1^{m_A} \phantom{a} a_2^1 \phantom{a} a_2^2 \phantom{a} \ldots \phantom{a} a_{n_A}^{m_A}$ $-$ $(n_A \cdot m_A)$ вещественных чисел, элементы матрицы $A$;
* $n_B \phantom{a} m_B$ $-$ два целых числа, количество строк и количество столбцов в матрице $B$; 
* $b_1^1 \phantom{a} b_1^2 \phantom{a} \ldots \phantom{a} b_1^{m_B} \phantom{a} b_2^1 \phantom{a} b_2^2 \phantom{a} \ldots \phantom{a} b_{n_B}^{m_B}$ $-$ $(n_B \cdot m_B)$ вещественных чисел, элементы матрицы $B$;
* $n_C \phantom{a} m_C$ $-$ два целых числа, количество строк и количество столбцов в матрице $C$; 
* $c_1^1 \phantom{a} c_1^2 \phantom{a} \ldots \phantom{a} c_1^{m_C} \phantom{a} c_2^1 \phantom{a} c_2^2 \phantom{a} \ldots \phantom{a} c_{n_C}^{m_C}$ $-$ $(n_C \cdot m_C)$ вещественных чисел, элементы матрицы $C$;
* $\lambda \in \mathbb{R}$ $-$ вещественное число $\lambda$, на которое умножается матрица $B$.

*Все числа внутри каждой из строк разделены ровно одним пробелом. Гарантируется, что каждое из них можно преобразовать при помощи вызова* `float(...)` *из стандартной библиотеки Python.*

### На входные данные также накладываются следующие ограничения:
* $0 < n_A, m_A, n_B, m_B, n_C, m_C \leq 256$
* Рассматриваются только конечные числа с плавающей запятой (IEEE754 double precision, но без бесконечностей и NaN'ов)
  * $\phantom{a} -\infty \phantom{a} < \phantom{a} a_i^j, b_i^j,c_i^j \phantom{a} < \phantom{a} +\infty \qquad \forall i, j$
  * $\phantom{a} a_i^j, b_i^j, c_i^j \phantom{a} \neq \phantom{a} NaN \qquad \forall i, j$

## Формат выходных данных (файл `output.txt`) 
Файл `ouput.txt` должен содержать ровно одну строку, либо ровно три строки:
* $r \in \{0, 1\}$ $-$ результат выполнения (0 - невозможно вычислить, 1 - вычислено);
* Если вычисления оказались возможными ($r = 1$), то также необходимо вывести следующие две строки:
  * $n_X \phantom{a} m_X$ $-$ два **целых** числа, количество строк в матрице $X$ и количество столбцов в матрице $X$;
  * $x_1^1 \phantom{a} x_1^2 \phantom{a} \ldots \phantom{a} x_1^{m_X} \phantom{a} x_2^1 \phantom{a} x_2^2 \phantom{a} \ldots \phantom{a} x_{n_X}^{m_X}$ $-$ элементы матрицы $X$ (числа с плавающей запятой).
  
*В случае, если строка содержит более одного числа, все числа в строке необходимо разделить **ровно одним** пробелом. Гарантируется, что число с плавающей запятой `f` будет преобразовано в строку корректно, если использовать стандартный вызов* `str(f)`.

## Пример 
Найти матрицу $X = A \times (\lambda \cdot B + C^T)$, при заданных значениях:
$$A=\biggl(\matrix{1 & 2 \cr 3 & 4}\biggr) \quad B=\biggl(\matrix{4 & 5 \cr 6 & 7}\biggr) \quad C=\biggl(\matrix{1 & 0 \cr 0 & 2}\biggr) \quad \lambda=5$$


Файл `input.txt` будет выглядеть следующим образом: 
```
2 2 
1 2 3 4 
2 2 
5 6 7 8 
2 2 
1 0 0 2 
5
```

Файл `output.txt` для приведенного примера будет выглядеть следующим образом: 
```
1 
2 2 
96 114 218 258
```
