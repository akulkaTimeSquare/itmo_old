# Схема Горнера

## Цель работы
Использование теоремы Безу и схемы Горнера для вычисления значения полинома в точке.

## Задание 
Используя схему Горнера, вычислить значение полинома $p(x)$ с целыми коэффициентами в целочисленной точке $x_0$:

$$p(x) = a_nx^n + a_{n−1}x^{n−1} + . . . + a_1x + a_0 = \biggl(\bigl((a_n)x + a_{n-1}\bigr)x + \ldots\biggr)x + a_0, \mbox{ при } x = x_0.$$

## Порядок выполнения работы 
* Решение должно представлять из себя программу на Python 3.9+ в файле `solution.py`, считывающую входные данные из файла с именем `input.txt` в текущей ~~аудитории~~ директории и выводящую результат в файл с именем `output.txt` в текущей директории.
* Запуск программы должен быть возможен при помощи вызова `python solution.py` в текущей директории.

---

## Формат входных данных (файл `input.txt`)
Файл `input.txt` содержит ровно три строки в указанном порядке: 
* $n \in \mathbb{N}_0$ $-$ степень полинома; 
* $a_n \quad a_{n−1} \quad a_{n−2} \quad \ldots \quad a_2 \quad a_1 \quad a_0$ $-$ коэффициенты полинома (от старшей степени к младшей), разделённые ровно одним пробелом, каждый коэффициент $a_i \in \mathbb{Z}$ $-$ целое число;
* $x_0 \in \mathbb{Z}$ $-$ точка, в которой необходимо вычислить значение полинома $p$ с данными коэффициентами.

### На входные данные также накладываются следующие ограничения:
* $n \leq 10^{1000}$
* $|a_i| \leq 10^{1000}$
* $|x_0| \leq 10^{1000}$

## Формат выходных данных (файл `output.txt`) 
Файл `ouput.txt` должен содержать ровно одну строку:
* $y0 = p(x0) \in \mathbb{Z}$ $-$ значение полинома $p(x)$ в точке $x_0$.

## Ограничения времени исполнения
При тестировании на каждый запуск программы накладываются следующие ограничения:
* Время работы: 2 секунды;
* Объём используемой оперативной памяти: 256 МБ.

## Пример 
Вычислить значение полинома $p(x)$ в точке $x_0$: 
$$p(x) = 434x^5 + 578x^4 − 1250x^2 + 3657x − 10, \mbox{ при } x_0 = −235$$

Файл `input.txt` будет выглядеть следующим образом: 
```
5
434 578 0 -1250 3657 -10 
-235
```

Файл `output.txt` для приведенного примера будет выглядеть следующим образом: 
```
-309286450873155
```
