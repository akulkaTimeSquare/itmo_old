# СЛАУная лабораторная

## Цель работы
Реализовать функцию-решатель произвольной системы линейных алгебраических уравнений из двух уравнений с двумя неизвестными.

## Задание 
Решить систему линейных алгебраических уравнений:
$$\biggl\lbrace \matrix{a \cdot x &+& b \cdot y &=& p \cr c \cdot x &+& d \cdot y &=& q, }$$
*где* $a, b, c, d, p, q \in \mathbb{R}$ $-$ *параметры, произвольные вещественные числа, а* $x$ *и* $y$ $-$ *неизвестные (также вещественные числа).*

## Порядок выполнения работы 
* Реализовать на языке Python в виде функций следующие операции: 
  * алгоритм решения вещественнозначной системы из двух линейных алгебраических уравнений с двумя вещественными неизвестными.

---

## Формат входных данных (файл `input.txt`)
Файл `input.txt` содержит ровно одну строку: 
* $a \phantom{a} b \phantom{a} c \phantom{a} d \phantom{a} p \phantom{a} q \phantom{a} \in \mathbb{R}$ $-$ вещественные числа, коэффициенты и свободные члены системы уравнений.

*Все числа внутри каждой из строк разделены ровно одним пробелом. Гарантируется, что каждое из них можно преобразовать при помощи вызова* `float(...)` *из стандартной библиотеки Python.*

### На входные данные также накладываются следующие ограничения:
* Рассматриваются только конечные числа с плавающей запятой (IEEE754 double precision, но без бесконечностей и NaN'ов)
  * $\phantom{a} -\infty \phantom{a} < \phantom{a} a, b, c, d, p, q \phantom{a} < \phantom{a} +\infty$
  * $\phantom{a} NaN \notin \left\\{ a, b, c, d, p, q \right\\}$

## Формат выходных данных (файл `output.txt`) 
Файл `ouput.txt` должен содержать **ровно одну строку**, которая, *в зависимости от результата работы*, должна иметь следующий вид:
* `0` $-$ в случае, если система уравнений *несовместна* (то есть, не имеет решений);
* `1 s t` $-$ в случае, если система уравнений имеет бесконечно много решений, каждое из которых имеет вид $y = s \cdot x + t$;
* `2 x0 y0` $-$ в случае, если система уравнений имеет единственное решение $(x, y) = (x_0, y_0)$;
* `3 x0` $-$ в случае, если система уравнений имеет бесконечно много решений вида $(x, y) = (x_0, y_0) \quad \forall y_0 \in \mathbb{R}$;
* `4 y0` $-$ в случае, если система уравнений имеет бесконечно много решений вида $(x, y) = (x_0, y_0) \quad \forall x_0 \in \mathbb{R}$;
* `5`  $-$ в случае, если любая пара вещественных чисел $(x_0, y_0) \in \mathbb{R}^2$ является решением системы уравнений.

*В случае, если строка содержит более одного числа, все числа в строке необходимо разделить **ровно одним** пробелом. Гарантируется, что число с плавающей запятой `f` будет преобразовано в строку корректно, если использовать стандартный вызов* `str(f)`.

* Время работы: 1 секунда;

## Примеры

### Пример 1
Решить систему линейных уравнений:

$$\biggl\lbrace \matrix{ x & + & y & = & 1 \cr 2x & + & 2y & = & 2 }$$

#### Файл `input.txt` будет выглядеть следующим образом: 
```
1 1 2 2 1 2
```

#### Файл `output.txt` для приведенного примера будет выглядеть следующим образом: 
```
1 −1 1
```

### Пример 2
Решить систему линейных уравнений:

$$\biggl\lbrace \matrix{ 2y & = & 1 \cr 4y & = & 2 }$$

#### Файл `input.txt` будет выглядеть следующим образом: 
```
0 2 0 4 1 2
```

#### Файл `output.txt` для приведенного примера будет выглядеть следующим образом: 
```
4 0.5
```
